## Staleness-Aware Asynchronous Multi-Node Sensor Fusion for Robust Indoor Activity Monitoring
# 1. Introduction
Indoor travel behaviour is a well-studied behavioural proxy for cognitive status. The clinical wandering literature defines dementia- related locomotion as manifesting in direct, lapping (circuitous, repeating-loop), pacing (back-and-forth), and random (disoriented, non-repeating) spatial patterns, the same four-way typology adopted in this paper. Passive, infrastructure-mounted sensing, as opposed to wearables, which require sustained compliance, or cameras, which raise privacy concerns, is an attractive substrate for continuously capturing this signal unobtrusivel. We first present the design of a staleness-aware asynchronous fusion architecture for a four-node PIR sensor mesh. Each node uses its own inter-arrival statistics to compute an adaptive staleness threshold. A continuously decaying exponential confidence weight, rather than a binary include/exclude decision, determines each node’s contribution to the fused output. Next, we construct and release a labelled dataset of 100 recordings from 25 participants performing four clinically motivated travel patterns, comprising 150921 synchronized 200 ms fusion snapshots (8.4 hours total), with full per-node staleness, weight, and freshness metadata retained at every snapshot. The data collection scenario is depicted in Fig. 1. Further, we design a 59- feature representation over the fused stream (node-transition, dwell-time, distance, and staleness statistics) and evaluate four classifiers.
