## Staleness-Aware Asynchronous Multi-Node Sensor Fusion for Robust Indoor Activity Monitoring
# 1. Introduction
Indoor travel behaviour is a well-studied behavioural proxy for cognitive status. The clinical wandering literature defines dementia- related locomotion as manifesting in direct, lapping (circuitous, repeating-loop), pacing (back-and-forth), and random (disoriented, non-repeating) spatial patterns, the same four-way typology adopted in this paper. Passive, infrastructure-mounted sensing, as opposed to wearables, which require sustained compliance, or cameras, which raise privacy concerns, is an attractive substrate for continuously capturing this signal unobtrusivel. We first present the design of a staleness-aware asynchronous fusion architecture for a four-node PIR sensor mesh. Each node uses its own inter-arrival statistics to compute an adaptive staleness threshold. A continuously decaying exponential confidence weight, rather than a binary include/exclude decision, determines each node’s contribution to the fused output. Next, we construct and release a labelled dataset of 100 recordings from 25 participants performing four clinically motivated travel patterns, comprising 150921 synchronized 200 ms fusion snapshots (8.4 hours total), with full per-node staleness, weight, and freshness metadata retained at every snapshot. The data collection scenario is depicted in Fig. 1. Further, we design a 59- feature representation over the fused stream (node-transition, dwell-time, distance, and staleness statistics) and evaluate four classifiers. Finally, we evaluate robustness to simulated packet loss by replaying each node’s real, reconstructed arrival timeline across three fusion strategies, showing that the proposed adaptive weighting degrades markedly more gracefully than a fixed threshold.<img width="1364" height="768" alt="fig_subjectNode" src="https://github.com/user-attachments/assets/daa3045f-1a95-4b99-8321-99f3f7f0481b" /> Fig. 1: A scenario for data collection using four sensor probes and an installed community Wi-Fi for motion detection.
# 2. System Design
Sensor Node Hardware: Each of the four sensor nodes is built around a low-cost, battery-powered microcontroller platform designed for fully cable-free corner placement (Fig. 1). Each sensor node uses an ESP32 microcontroller with integrated Wi-Fi/BLE, an HC-SR04 ultrasonic sensor for distance measurement, and a PIR sensor for motion detection. A DHT11 sensor records ambient temperature and humidity for future calibration. The node operates on a 3.7 V Li-ion battery with a TP4056 charging circuit and generates event-driven samples at approximately 150–250 ms intervals. Communication is currently performed through a USB-serial interface, while BLE
support remains available for future wireless deployment. The PIR motion sensor acts as the primary event trigger, and an HC-SR04 ultrasonic ranger, which measures the distance to the detected occupant along that node’s line of sight. Configuration and Node Placement and Travel Protocol: Data was collected in a rectangular, furniture-cleared indoor room to eliminate spurious ultrasonic reflections. The four nodes were corner mounted at a uniform height of 1m–1.2m, angled slightly downward: Node 1 (front-left), Node 2 (front-right), Node 3 (rear-left), and Node 4 (rear-right), as illustrated schematically in Fig. 1.
